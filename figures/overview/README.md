当前为用户要求的精简版：标签从311压至169个汉字，减少重复描述并保留各问方法与信息边界。旧详细版及原脚本在`versions/2026-09-10-detailed/`。

用于论文“1.3 我们的工作”，参考用户提供的`05-CUMCM2025C-神秘卷3.pdf`第3页的四问并列组织方式，内容与图形由当前项目重新绘制。

## 文件与编辑

- `总体流程图.svg`：原生SVG，文字为可编辑的`text/tspan`，节点为独立`g/rect`，箭头为独立路径；无内嵌位图。适合矢量编辑器调整文字、位置、颜色。
- `总体流程图.drawio`：可用draw.io/diagrams.net打开的节点与连线源文件，便于拖拽调整。未调用远程服务或上传项目数据。
- `总体流程图.pdf`：LaTeX使用的矢量版本，文字字体嵌入；与SVG来自相同场景定义。
- `总体流程图.png`：300 dpi预览；论文使用PDF。
- `manifest.json`：来源、尺寸、字体及输出哈希。

SVG保留可编辑文字，因此显示依赖本机字体。默认与正文相同的STSong常规体，提供宋体和Noto Serif CJK后备；字体变化可能改变行宽。PDF用于固定论文显示效果。

## 复现

在仓库根目录运行`python3 src/draw_workflow.py`。已有输出时脚本拒绝覆盖；确认保留了人工编辑后才使用`--overwrite`。代码自动把SVG、PDF和draw.io副本放入`paper/overleaf/figures/`，保持论文工程独立可编译。

后续修改可选直接编辑SVG/draw.io，或修改脚本中的中文节点后重新生成。手动编辑SVG/draw.io之后，PDF不会自动更新，应从编辑器重新导出PDF并替换论文插图；不要直接重跑脚本覆盖手工修改。
