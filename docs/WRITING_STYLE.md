# 中文论文写作规范

适用于本项目论文、摘要、模型假设、符号说明、图表文字及结果分析。新写和修改时均执行。

## 来源与使用

采用 [blader/humanizer](https://github.com/blader/humanizer) 的 Humanizer skill，项目内文件为 `.agents/skills/humanizer/SKILL.md`。本次安装版本为 3.0.0，固定上游提交 `9862685f575c65a8247f90369951df1b3416e3d6`，许可证为 MIT，原文及许可证随项目保留。

先读本规范，再使用 Humanizer 检查空泛表达、重复句式、夸大结论及聊天残留。本规范优先于其通用文风和输出建议。目标是自然、准确、简洁的中文学术表达；保留正式语气，不加入个人感受、幽默、比喻或虚构细节。保留中文标点、必要标题、编号及数学记号，不机械套用英文标点规则。

## 表达要求

- 购电安排统一使用“策略”命名，正文、摘要、表格、图例和流程图保持一致；名称调整不改变决策变量、购电量、费用公式及原始结果。

- 优先使用正向陈述：结论写所用方法、评估条件、费用和效果；统计区间跨越零点时直接报告区间，技术限制改写为具体规则或改进方向。删除“不作一般性最优结论”“不表述为独立盲测最优”等自我审稿式收尾，保留原始证据和比较条件。

- 从评委的阅读需要出发选词：优先写“储能控制方法”“允许的储电量范围”“达到上下限”“计划增购量”，避免用“执行器”“可达边界”“触边”“试算增量”等程序用语代替具体含义。“购电保护量”统一称“用电安全余量”，首次说明它加在预测负载上；用于kWh的SOC统一称“储电量”。必要的模型名称和数学术语保留，但首次应说明在本题中的含义。

- 储能DP中的“终端代价/终端价值”统一写作“日末补电费用估计”，日末电量不足的变量写“日末储电量缺额”。名称调整不改变原公式、参考电量或实际费用计算。

- 每幅编号图和每张编号表均须在正文引用，并用一句话交代其内容或发现；优先融入已有分析，避免只重复标题。删去图表时同时处理正文引用。

- 正文直接面向评委展示模型、结果和解释。删除“报告时需明确”“上述变化仅反映本例”等写作提醒和无新增信息的收尾；试验条件在设置处交代清楚，结果段写完具体发现即结束，不追加泛泛的自我辩护。
- 通读时逐段检查“仅作为……依据”“不提供……保证”“不代表……”“不能视为……”“尚未分别识别”等防御性句式。无独立信息的直接删去；有技术含义的改为实际采用的方法、明确的比较条件或数据结论。运行约束、数据使用范围和费用定义仍须准确，不能因去套话而改变模型。

- 模型和算法在正文首次出现时写“中文名称（缩写）”，之后统一使用缩写，如MILP、LP、DP，不展开英文全称。没有通用缩写的名称采用常用英文名，如“岭回归（Ridge）”，后续用Ridge。不在首次定义前使用未解释的缩写作章节标题。
- 求解正文说明所求模型和数学方法；SciPy、HiGHS等软件名称及运行限时、容限等实现设置放在代码复现说明中。

- 优先提高信息密度：用最短且易懂的表达保留条件、方法和结果。按段落压缩，删除重复说明，不止替换词语。
- 各问保留结论，集中回答该问并概括主要结果；需要去重时优先删减结论之前的重复汇报，不删除结论环节。
- 表格优先保留题目明确要求的输出和关键效果对照；描述性统计、误差细项及数值核验能用短段说明时不单独成表。参考论文的表格数量不作为硬性上限。
- 参考《神秘卷三》的问题要求写法：共同目标和交付要求集中说明，每问只保留独有条件及任务，不反复罗列附件、建模要求和结果清单。
- 正文解释公式的含义和选择依据、图表反映的规律；不要逐项复述公式、表格或流程图已有内容。技术细节保留到足以理解和复现，重复的检查过程可压缩。
- 少用“执行器”“隐性试算”“信息边界”等抽象表达，能写成“储能控制”“尚未确认的购电计划”“当时可用的数据”时直接说明；必要数学术语仍保留。

- 直接写明对象、操作和结果。用常用、完整的词语，不为压缩篇幅省略必要主语、条件或宾语。
- 一句话集中说明一件事。多个独立条件分句或分句号表达，不把数项假设挤进一个长句，也不把简单内容扩写成解释段。
- 避免用“口径”笼统代指不同概念。按实际含义写“计量方式”“时间对应关系”“效率假设”“费用计算规则”或“比较条件”；能直接说明规则时，省去概括词。不得全文机械替换成同一个词。
- 正文不出现“这里不能说”“只能说”“主结论应表述为”“不要声称”等写作指令。将其中有效的技术信息改写为结论或适用条件。
- 保留影响结论的限制，集中放在对应假设、结果分析或模型局限中。不要每段重复防御性声明，也不能为了流畅而删掉实质限制。
- 删除没有信息增量的套话，如“值得注意的是”“具有重要意义”“为……提供有力支撑”。避免无必要的“不是……而是……”和刻意凑成三项的排比。
- 同一概念使用同一名称，专业术语首次出现时说明含义。保留“边际价值”“线性松弛”等必要术语，不用含糊的日常词替换。
- 用数据和比较条件支撑结论。未经证明不写“全局最优”，未经统计检验不写“显著”，未做跨年验证不宣称跨年适用。

## 修改示例

以下示例说明句式，使用时须核对当前模型与证据。

| 原表达 | 建议表达 |
|---|---|
| 按统一口径计量充放电量 | 充放电量均按交流侧计量。 |
| 改变效率口径重新求解 | 将 90% 解释为往返效率后重新求解。 |
| 储电量跨日衔接 | 每日初始储电量等于前一日结束时的储电量。 |
| 不计售电收入 | 不考虑向电网出售电量获得的收入。 |
| 这里不能说全局最优，只能说当前配置下有效 | 该策略满足运行约束，计算费用见表中结果。 |
| 主结论应表述为：在已披露的假设下…… | 在上述假设下，所得购电计划满足供电及储能运行约束。 |

## 修改与核验

1. 先理解整段要说明的问题，再改写句子；不要只逐词换同义词。
2. 对照原文检查数字、单位、公式、变量、时间范围、比较对象、假设状态和限制条件，确保技术含义不变。证据不足时保留明确的不确定性，不补造事实。
3. 通读检查绕口句、重复解释及内部审稿话术。检索“口径”“不能说”“只能说”“应表述为”等只是定位线索，应逐处判断。
4. 默认仅交付修改后的文本与必要的简短说明，不输出初稿、自评和终稿三套内容。修改 LaTeX 正文后编译检查；安装规范本身不需要重跑模型。
5. 润色不更改模型决定、数值结果和公式。需要技术变更时单独说明问题；线上同步仍按项目既有授权规则执行。
