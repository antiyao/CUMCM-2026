# 图7绘图数据

日期：2025年9月8日。方案：第二问固定Ridge预测、0.8分位数安全余量、50 kWh储电量网格的主方案。

购电策略和日初储电量取自`results/c2026/annual_slots.csv`的`case=q2`。用当前`src/problem2.py`重新生成截至该日的因果预测及历史残差，再调用`src/microgrid.py`重建DP价值函数。逐区间重放后的充放电、紧急购电、弃电和储电量与保存轨迹的最大差异小于4×10⁻¹² kWh。

## 直接绘图所需文件

| 文件 | 内容与尺寸 |
|---|---|
| 阈值与运行轨迹.csv | 145个时刻，包括00:00和24:00；实际储电量、144个决策阈值、紧急购电、充放电、预测值、电价及事件标记 |
| 边际价值矩阵.csv | 热力图宽表：192个储电量区间中点为行，145个时刻为列 |
| 边际价值热力图.csv | 同一热力图的长表：27,840行，包含时刻、储电量区间上下限及边际价值 |
| 原始价值函数矩阵.csv | 193个储电量网格点为行，145个时刻为列；值为V(t,E)，单位元 |
| 历史残差样本.csv | 此前14天的2016个净负载残差；同一钟点小时合并84个样本 |
| figure7_arrays.npz | 原始矩阵、网格、阈值、轨迹、预测净负载、购电量、电价和逐时段残差样本数组 |
| 核验记录.json | 来源哈希、计算参数、依赖版本、重放误差与边界检查 |

CSV使用UTF-8 BOM编码，可用Excel、Python或Matlab读取。储电量网格为1200、1250、……、10800 kWh，共193点；时间步长为10分钟。

## 坐标与字段

- 横轴：`time_hour`，单位小时，范围0至24；`time`为对应的HH:MM标签。
- 储电量轨迹：`actual_soc_kwh`表示该时刻的内部储电量，包含145个端点。相邻端点间按区间恒功率作线性连接即可，无需平滑。
- 留电阈值：`reserve_threshold_kwh`表示该时刻开始的十分钟区间的阈值，适合阶梯线。24:00没有新决策，该单元格留空，不应填0。
- `plan_kwh`、`load_kwh`、`pv_kwh`、`charge_kwh`、`discharge_kwh`、`emergency_kwh`等均表示从该时刻开始的十分钟区间电量；24:00行这些字段留空。
- 紧急购电标记：`emergency_flag=1`表示该区间紧急购电量超过10⁻⁷ kWh；共44个区间。`economic_hold_flag=1`表示尚能多放电却选择留电并紧急补购；共36个区间。
- 热力图纵轴：`energy_midpoint_kwh`，取1225、1275、……、10775 kWh；每个数值代表相应50 kWh区间上的斜率。
- 热力图颜色：`marginal_value_yuan_per_kwh`，单位元/内部kWh，由相邻网格点计算`-(V[t,j+1]-V[t,j])/50`。数据没有平滑或裁剪；约10⁻¹⁵量级的负值为浮点误差。

## 热力图与阈值的关系

热力图提供的是当前时刻的`-∂V(t,E)/∂E`。阈值由下一时刻的`V(t+1,E)+5p(t)ηdE`最小化得到，ηd=0.9；费用在10⁻¹⁰元以内相同时取较小储电量。

因此，阈值不能直接解释为当前热力图某两种颜色的固定分界线。若需要绘制用于本区间决策的后续边际价值，应使用价值函数矩阵的下一时间列，即NPZ中的`marginal_value_yuan_per_kwh[1:]`。

23:50的阈值为1200 kWh。24:00的边际价值在6000 kWh以下为0.4125555556元/kWh，在6000 kWh以上为0。6000 kWh处为不可微拐点，矩阵用两侧区间斜率表达，不人为添加一个平滑导数。

本数据对应第二问主方案。论文中以冻结贪心购电策略进行控制器比较的实例属于另一组条件，标注数值应从本数据读取。

```bash
python docs/reviews/2026-09-13-online-review/export_figure7_data.py --out /一个尚不存在的目录
```
