# 第二问改进实验预先固定方案

本文件在本轮改进策略结果计算前写出；之前已经查看同一年度基线结果，因此整轮是回溯研究，不是独立外部盲测。

## 不改变的项目
- 价格来自附件1；负载和光伏来自附件2。不使用附件3/4，不读取未来实际值。
- 原代表功率前十分钟解释、效率各0.9、上下限1200/10800、十分钟充放电上限5000/6保持一致。
- 2月1日从6000 kWh开始，解释为1月观测期储能待机；执行的真实日末电量连续传递。
- 午夜MILP规划终点6000 kWh与原代码一致；执行仍用原贪心规则。实际终点不能重置。
- 普通购电量午夜冻结；补电费5倍；紧急购电不充电；剩余电可不利用、无售电收益。

## 本轮改动
1. 基线A：负载前7日同期、光伏前7日平均，没有风险保护。
2. 偏差校正B：在A预测上加最近3个已完成日的原始预测残差均值；负载与光伏预测分别截断为非负。
3. 风险保护C：A预测保持不变，加历史净负载残差的经验上分位数作为规划保护量。
4. 组合D：B预测加其对应残差的风险保护。

## 风险保护与选择
- 每小时单独汇集此前最多14个完整日、同一小时6个十分钟点的净负载残差，保留夜间与日间时段差异。
- 在同一个小时内给6个时段使用相同的非负保护量。以kWh计。
- 候选 q={无保护,0.65,0.80,0.90}，不是把80%当作通用解析最优值。
- 分别在1月15日至31日作17天连续校准回放，初值6000；若经济总费用差小于浮点容差则偏好较低保护。
- 仅用这段1月校准费用为C与D选择q，然后冻结至2--12月；残差样本随已观测历史更新，但不按未来结果调参。
- 这段1月是虚拟验证回放，不改用于2月正式比较的“1月待机”共同初始化。
- 对外报告A/B/C/D全部结果，不只报告最好的一项，不预设改善幅度。

## 核验与局限
- 每条轨迹重新前向核算，单位、储能、互斥、边界、费用、跨日连续、样本数。
- 记录所有实际终点，并以固定终端电量的独立补充实验排除消耗期末电量影响；补充实验若尚未完成则不声称已做。
- 本轮不改电池实时控制，不称随机规划全局最优，不生成时标仍待核实的正式result2.xlsx。
