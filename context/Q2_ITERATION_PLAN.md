# 第二问迭代：实验协议

本轮用户已授权实际审查外部改进说明并迭代。只扩展Q2；既有v1源码、数据、五本结果及Q1/Q3/Q4数值保留。本轮已看过2025年全期既有成绩，属于回溯开发，即使模型接口严格因果也不冒称外部盲测。

## 首批候选（先冻结，再看本轮全年结果）

1. 现有点预测/裕量参考控制/裕量贪心三个基线，追加无裕量的同预测贪心以定位外部基线差异。
2. 说明中的3日预测偏差修正与14日同小时经验净负载分位保护，分位候选0、0.65、0.80、0.90，只以1月15—31日的虚拟回放选取；之后冻结参数，误差窗仅用此前完整日。
3. 在同一小时保护下，对保留部分计划SOC的价格条件反馈做小规模候选：保留系数0/0.25/0.5，只有当前价低于后续已知固定价峰值时启用；用同一1月回放选择。
4. 3或5个历史完整日误差块的共享合同场景规划。所有场景共享0点q；场景内可预见整条误差的补救仅是乐观规划代理，正式执行独立反馈，不能写成可实施全知补救。必要时报告没有改善。

候选取舍由1月回放决定，不能按2—12月最便宜的行回填正式主方案。若使用滚动策略选择，只能根据决策时已完成的候选回放费用，须独立记录并重算当前SOC，不复制他策略的状态。进一步探索须另登记，不静默扩展搜索。

## 实际迭代增补（全期新实验前固定）

- annual_core_v2中，一月选出的小时0.65分位/价格保留方案并未优于旧全年greedy；偏差+小时0.8只小幅改善。进一步明确滚动选择器为：仅使用过去14个完整日的shadow策略费用减SOC变动替代价值，在旧动态裕量greedy及同一无偏差/3日偏差×四个小时分位候选间选择；每天以选择器自身真实SOC重新规划，不复制影子状态。影子从1月15日6000起虚拟运行，实际状态仍至2月1日保持6000。全期结果已被研究者看过，继续标回溯研究。
- 场景模块在全年前为计算效率改为3/5个完整日块分位代表点、等概率1/S近似。S≤5时每个概率≥1/5，先消除u/w、充放循环，再按共享q补量替代紧急充电，可证明代理目标不增；严格检查后仍保留MILP回退。不同代表/概率近似不是与旧不等概率模型同一个最优问题，新实现重新一月校准，不能只宣称无损提速。
- annual_final_v3的场景代理、adaptive_annual_v3的影子选择均没有优于已有贪心裕量基线。最后增加一个针对诊断的候选：直接最小化历史完整日块在同一个greedy控制器下的平均实际购电费，避免全知补救与线上执行不一致；共有q、同一实际执行规则、14/28历史窗只Jan选择，L-BFGS-B最多50步，初值为旧裕量计划并始终保留。终端短缺用固定min(p)/eta_c估值，明确为代理终端价值；非光滑优化仅best-found，无全局最优证书，不按全年结果反调搜索预算。
