## 1. Problem Archetype

本文是分层回归与曲线外推问题：

1. 对9个固定电流分别拟合“剩余放电时间—电压”二次曲线；
2. 再拟合三项二次系数对 `log(I)` 的线性关系，从离散电流推广到20–100A任意电流；
3. 对衰减状态曲线间的时间差比作常数外推，补全状态3低电压段。

这种“组内曲线→跨组参数回归→未观测组插值”的层次结构可迁移，但论文的误差均在训练数据上计算，55A没有真值，衰减外推没有留出验证。附录又出现MRE函数无法处理非连续/不足231点、`TimeAll/TineAll`拼写错误和55A表与通用公式不一致，因此结果只能在明确边界内使用。

## 2. Problem Decomposition

1. **固定电流曲线**：删除每条曲线开始阶段10%数据，把分钟换算为天，以 `x=U-9`、`y=T_remaining`拟合二次式。
2. **样本筛选/MRE**：倒序电压，从9V起找相邻差绝对值≤0.005V的点；优先找231个连续点，否则取前231或全部可用点。
3. **9.8V预测**：把 `U-9=0.8`代入30–70A五条二次式并换算为分钟。
4. **任意电流模型**：对九条 `T(U)=p1 U²+p2 U+p3`的系数分别回归 `p_i=a_i log I+b_i`，给55A插值曲线。
5. **衰减状态3**：在已知段计算 `R2=(T_yellow-T_black)/(T_green-T_yellow)`，以9.765–10V的平均比1.2094外推剩余153个电压点，再用 `T_remaining=Tmax-T_predicted`。

## 3. Data Processing

- 每列电压中的0被删除，时间向量截到相同长度。
- 每条曲线前10%样本被删除，理由是初始钝化阶段；没有给电化学阈值或删前/删后误差比较。
- 时间由分钟除以1440转为天，电压中心化为 `U-9`，有利于减少系数数值尺度。
- MRE筛选把电压序列倒序，从截止电压附近搜索相邻差≤0.005V的位置。
- 90A仅230个、100A仅189个合格点，论文改变题定231点样本量；各电流MRE不可完全同口径比较。
- 问题二用九个电流的三组系数作二次阶段回归；每个线性系数模型只有9个点、2个参数、残差自由度7。
- 问题三删除状态3中的NaN后，用索引101到已知末端求比例均值，再按索引位置补尾；未校验NaN是否只在连续尾端。

## 4. Models Used

### 固定电流二次曲线

**Purpose:** 预测给定电流和电压下的剩余/已放电时间。

**Inputs:** 电压U、采样时间、电流组20–100A。

**Outputs:** 九条 `T_remaining=a(U-9)^2+b(U-9)+c` 及等价 `T_discharge(U)`。

**Why selected:** 五次多项式样本内R²可到1，作者为降低复杂度改用二次式，仍声称R²约0.9999。

**Important assumptions:** 删除前10%后曲线可由二次式描述；9V截止处无需强制剩余时间为0。

**Key equations or mathematical structure:** 二次OLS，`T_discharge=Tmax-T_remaining`。

**Implementation notes:** 未加物理边界 `T_remaining(9)=0`，常数项导致截止处剩余时间为-27.36至17.856分钟。

### 系数对数电流回归

**Purpose:** 从九个离散电流推广到任意20–100A恒流曲线。

**Inputs:** 九条二次式的三组系数与 `log(I)`。

**Outputs:** `T=(0.4227 ln I-2.103)U²+(-7.549 ln I+37.62)U+32.38 ln I-161.9`。

**Why selected:** 三组系数随 `log(I)`图形近似线性，作者称拟合度均超过95%。

**Important assumptions:** 系数—`ln I`关系在20–100A内线性；三组系数可独立拟合。

**Key equations or mathematical structure:** 每个系数各做9点一元线性回归，再代回电压二次式。

**Implementation notes:** 验证仍使用同九个电流；55A仅插值演示，无55A测量曲线。表11数值与该代码公式严重不一致。

### 常数差值比衰减外推

**Purpose:** 用新电池、衰减1、衰减2及状态3已知段补全状态3。

**Inputs:** 同电压下四条曲线的时间差 `D1,D2,D3`。

**Outputs:** 状态3预测时间和剩余时间。

**Why selected:** 作者观察约10.3V以下R1趋稳，且状态3已知段R2形态相似。

**Important assumptions:** 9.765–10V平均 `R2=1.2094` 可外推到9V；误差不随电压累积。

**Key equations or mathematical structure:** `T3=T2-(T1-T2)R2`，`T_remaining=Tmax-T3`。

**Implementation notes:** 预测前两行出现负已放电时间；无非负约束、比例不确定性或留出已知段验证。

## 5. Model Pipeline

`附件1九列电压 → 去0/删前10%/时间换天 → 九条二次曲线 → MRE与9.8V预测 → 三组系数对ln(I)回归 → 任意电流曲面/55A表`。

问题三独立走 `附件2四状态曲线 → 同电压时间差 → 比值R1/R2 → 选定窗口均值1.2094 → 状态3尾部外推 → 剩余时间`。

关键接口断裂有三处：正文允许非连续/不足231点MRE，公开`ccc`函数只找231个连续点；`FangDianTime`把剩余时间写入拼错的`TineAll`而返回未翻转的`TimeAll`；`TT`公式对55A的输出不等于表11。

## 6. Model Improvements

1. 用 `U-9`中心化并将分钟换天，改善二次系数数值尺度。
2. 以二次替代五次多项式，降低参数数和过拟合风险。
3. 对二次系数再做 `ln(I)`回归，把离散曲线提升为电流—电压二维响应面。
4. 以相邻衰减曲线差值比外推未知状态，利用同电池跨状态结构。

改进没有经过真正样本外验证。二阶段系数回归还把第一阶段估计误差当成无误差响应，未传播不确定性；常数比也没有区间或物理截断。

- 九宫格曲线把不同电流下测量值和二次拟合叠加，能快速发现随电流变化的曲率趋势；线条几乎重合但没有残差放大图。

## 11. Writing Structure

报告按三问分别完成“预处理—模型—误差—输出”，附录给出对应MATLAB函数，结构紧凑。问题一把剩余时间式与放电式分开，问题二用参数回归实现推广，问题三用跨状态结构补全，递进自然。

主要写作问题是精度措辞过强：摘要把MRE概括为0.0035–0.0178，遗漏表6的0.0281–0.0743；55A只预测无验证；状态3出现负已放电时间仍未讨论。应把训练拟合、同样本误差、插值和外推分别命名。

## 12. Strengths

1. `U-9`中心化和时间单位缩放使模型系数更稳定、物理含义更清楚。
2. 从五次降到二次体现复杂度控制意识。
3. 以系数对 `ln(I)` 回归构造二维响应面，迁移性强。
4. 提供大量公式、误差表和MATLAB代码，允许独立发现接口问题。
5. 9.8V预测和表12均可进行直接算术复核。

## 13. Weaknesses

1. 全部R²/MRE都在参与拟合的数据上，且先删除10%；没有留出电压、电流或电池。
2. 90A/100A不足231点却改变样本数，表6误差不可同口径比较；附录函数也不支持该分支。
3. 任意电流公式与55A表严重不一致，代码—结果未闭合。
4. 二次模型不满足截止电压处剩余时间为0；状态3外推还产生负已放电时间。
5. 常数差值比没有不确定性、噪声或窗口敏感性，不能验证衰减机理。

## 14. Reusable Techniques

### 分层响应面

**When useful:** 多组条件各有一条平滑曲线，且需插值到未观测条件时。

**Why useful:** 先拟合组内曲线，再对参数随条件变量建模，结构清楚、参数少。

**Limitations:** 第二阶段应传播第一阶段系数协方差，并用leave-one-group-out验证。

### 物理约束回归

**When useful:** 截止点、单调性、非负性等边界已知。

**Why useful:** 强制 `T_remaining(Um)=0`、`T≥0`和方向约束可避免高R²下仍出现物理错误。

**Limitations:** 约束必须来自题意/机理，不能为改善图形随意添加。

### 同口径误差抽样

**When useful:** 不同曲线的采样密度不一致。

**Why useful:** 固定电压网格或插值到共同网格后再计算MRE，保证样本量和覆盖区间可比。

**Limitations:** 相对误差在真实时间接近0时不稳定，应同时报告MAE/RMSE。

### 衰减曲线留段验证

**When useful:** 需要从已知前段外推未知后段。

**Why useful:** 在已知曲线中人为遮住尾段，可直接检验常数比假设和窗口选择。

**Limitations:** 同一电池内部验证不能替代跨电池/跨温度验证。

## 15. Competition Takeaways

1. 曲线拟合先写物理边界和单位，截止电压处剩余时间必须为0。
2. 选二次而非五次要用留出误差，不只比较训练R²和复杂度。
3. 各电流MRE必须使用共同电压范围和相同样本数；不足时说明不可比。
4. 二阶段系数回归用leave-one-current-out，并用55A真值验证插值。
5. 表格必须由最终代码自动生成；公式复算与55A表差数百分钟应在提交前拦截。
6. 外推模型要报告窗口、样本量、比例方差和预测区间，并强制非负。
7. 附录函数逐个做最小单元测试，尤其检查空索引、拼写和返回变量。
8. 摘要精度范围必须覆盖正文全部误差，不能遗漏不利电流组。
