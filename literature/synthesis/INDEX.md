## 4. 按验证需求

| 需求 | 优先查看 | 使用边界 |
|---|---|---|
| 残差与拟合诊断 | C007、B157、E176、C023、B050、C126 | 残差图和样本内 R² 不是外部验证。 |
| CV / hold-out 审计 | E025、C132、2020 C 信贷、C155、2017 B 拍照赚钱、B050 | 这些主要是泄漏、切分或比较口径案例。 |
| 时序验证 | E176、C126、C235、C228、C101 | E176 有留年证据；其余更多展示 rolling/grouped validation 缺口。 |
| 合成恢复 / 解析互证 | A090、B157、A022、D033 | 检查是否同模型 `inverse crime`。 |
| 同目标算法比较 | A090、B226、C038、A196、C228、2020 B 穿越沙漠 | 必须先核对数据、目标、约束和计算预算。 |
| 扰动敏感性 | A090、C308、A022、C038、2020 B 穿越沙漠、B157 | 单参数 OAT 不等于联合鲁棒性。 |
| 可行性与约束复算 | C038、C063、C235、A196、A242、B334 | 对最终解输出全部约束残差。 |
| 外部真值边界 | 2015 C 月上柳梢、E176、C155、B157 | 全库没有可信的端到端 L5。 |

## 5. 已知语料缺口

- 严格因果推断几乎没有覆盖。
- rolling-origin、盲样/外部真值和可信端到端 L5 普遍不足。
- 启发式最优性证书、多 seed 不确定度和端到端风险传播普遍缺失。
