# Modeling Quick Reference

这是从 32 篇逐篇蒸馏中提取的高频决策规则，用于赛期早期快速检查。它不是完整 playbook，也不代替当前题目的数据、假设和验证。括号中的论文代号可在 [`INDEX.md`](INDEX.md) 中定位。

## Problem decomposition

- 先建可解释基线或正向模型，再用残差、特殊情形或约束检查决定是否升级复杂度。（C007、A090、B226、B157）
- 对每个模型接口记录输入、输出、单位、时间窗和不确定性；接口通常比单个算法更易失效。（C126、C228、C038、C063、A196）
- 空间和动态题先做解析降维、状态压缩或事件定位，再使用启发式。（B226、B334、A196、A242）
- 小规模子问题优先保留解析解、精确枚举或 DP 基线。（A022、B159、穿越沙漠、D033）

## Data preprocessing

- 先切分数据，再在训练折内拟合缩放、填补、PCA、特征选择和超参数。（E025、C132、C155）
- 时间序列、重复测量和面板数据必须保留时间与个体边界。（C023、C132、C101、C235）
- 建模前自动做人数、日期、类别、矩阵维数和过滤数量闭合。（C126、C235、C101、C063）
- 先识别数据几何与 support：成分闭合、零值机制、最小类样本数和残差自由度。（C155、E025、B050）

## Regression and statistics

- 小样本先数参数和残差自由度；高 R² 不能补偿近饱和拟合。（C007、B050）
- R²、F、训练 accuracy 和目标下降属于样本内证据，不是独立预测验证。（C007、C023、B050、2020 C 信贷）
- 同时检查残差、共线性、变换前提和参数符号，不只看总指标。（C007、B050、B157）
- 概率模型应自动检查 `[0,1]`、单调性和校准；外推值应受物理边界限制。（2020 C 信贷、2017 B 拍照赚钱、C014）

## Forecasting

- 时序评价使用未来留出或 rolling-origin；本库时序论文普遍缺这一环节。（C126、C235、C228；E176 为有限正例）
- 复杂预测模型至少与季节朴素或低阶基线比较。（E176、C235）
- 若优化价格，需求模型必须真正依赖价格，否则目标容易单调退化到边界。（C126、C228、C235）
- 将预测区间或情景传入补货、定价和监测优化，而不是只传点预测。（C126、C228、E176）

## Machine learning

- preprocessing、feature selection、SMOTE、Optuna 和模型选择都应在 nested CV 内完成。（E025、C132、C155）
- 模型比较必须共享数据、折分、特征、调参预算和折外指标。（2020 C 信贷、E025）
- 多分类报告整数混淆矩阵、每类 support 和 macro 指标，并自动复算 F1。（C132、E025）
- 堆叠模型使用 out-of-fold 第一层预测；随机算法报告多 seed 分布。（C132、E025）

## Evaluation models

- 逐项确认指标正负向、归一化和量纲，再计算权重或综合分数。（2016 B、C085）
- 熵权或 AHP 结论必须做权重敏感性及排序复算。（C085、C007）
- 同数据综合得分只能说明内部排序，不是外部验证或因果证据。（C085、C101、C228）

## Optimization

- 每条正文目标和约束都应在代码中有对应项，并对最终解输出全部约束残差。（C038、C063、A196、2020 C 信贷）
- PSO、GA、DE、SA 和有限网格结果统一称 `best-found`，除非有下界、gap 或穷举证明。
- 只有共享数据、目标、约束、计算预算和可行域的算法结果才能互相验证。（A090、B226、A196）
- 解命中边界时扩大范围或报告安全裕量，不能直接宣称最优。（A022、B050、B157、A242）
- 小决策空间先做精确枚举/DP，再评估启发式 gap。（B159、穿越沙漠、B334）

## Robust / stochastic modeling

- 写“随机/鲁棒”前明确随机变量、情景概率、风险度量和传播路径。（C038、C063、C085）
- CVaR 必须检查损失方向、尾部选择和情景归一。（C038）
- 单参数扰动是敏感性，不是联合不确定性下的鲁棒性。
- 多资源事件先判断互斥、独立或共享潜变量；共享目标位置不能按独立试验相乘。（D033）

## Simulation

- 在复杂仿真前保留可解析特例、守恒关系或独立积分基准。（A022、A090、D033）
- 报告时间步、积分网格、射线数或样本数的收敛，而不是只展示一张曲线。（D033、A0175、A242）
- Monte Carlo 应固定 seed、重复运行并报告均值、分位数或误差条。（C308、穿越沙漠、A0175）
- 事件时间、状态转移和几何判定应只有一个共享实现并做单元测试。（B334、A196、A242）

## Validation

- L1–L5 是证据类型，不是质量分数；同时记录独立性、重复数和限制。
- 验证结论必须绑定具体目标；某模块的 L4 不能自动升级整条管线。（A090、B157）
- 对关键百分比、总数、时间差、F1、概率和约束做独立复算。（C132、A196、D033、B159）
- 异算法一致只有在数据、目标和约束一致时才有验证价值。
- 32 篇没有可信端到端 L5；不要把内部回代、同模型合成恢复或单次扰动写成外部验证。

## Sensitivity and robustness

- 参数表至少包含来源、单位、基线、范围、采样方式、输出指标和结论是否翻转。
- 边界最优、接近约束上限或参数卡边界时必须扩域或做裕量分析。（A022、A28、B050、B157、A242）
- 同时报告数值变化、可行率和决策是否改变，不只说“趋势稳定”。
- 对随机 seed、超参数、预处理阈值和联合情景做重复实验；单条 OAT 曲线不足以证明鲁棒。

## Reproducibility

- 至少保存输入 hash、可执行源码、环境、seed、运行命令、输出和数值容差。
- 代码截图和附件清单提高可审计性，但不是可执行复现包。
- 缺失附件应写 `referenced but unavailable / not assessable`，不能改写为“作者未实现”。
- 公式、代码和结果表必须三向闭合；主版本与伴随版本的证据边界应单独记录。

## Common failure modes

- 全数据预处理或聚类后再切分，造成验证泄漏。
- 将训练 R²/accuracy、目标下降或多模型一致称为外部验证。
- 正文算法名与代码实现不同，或比较算法没有相同目标/约束。
- 约束只写在论文中，代码中遗漏、注释掉或方向相反。
- 单调退化、边界解或有限网格最好点被称为全局最优。
- 单位、百分比分母、索引范围、候选数、维数或事件计数不闭合。
- 从价格—销量、促销—销量等相关关系直接推断因果。
- 上游预测或参数估计的不确定性在下游优化中被丢弃。
- 共享潜变量事件被错误当成独立试验。
- 有代码页图但缺数据、环境和运行输出，仍宣称可复现。
